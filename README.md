# Sleep Deprivation Game

An online multiplayer version of the [BrainFacts.org Sleep Deprivation Game](https://www.brainfacts.org/for-educators/for-the-classroom/2018/sleep-deprivation-game-081418) classroom board game.

**Play:** https://micahmats.github.io/sleep-game/

- Host a game to get a shareable link and code. Up to 30 players can join each game.
- Every game you host is its own room with its own link.
- The host's browser runs the game, so keep that tab open while playing.
- You can also play on one device, passing it around or against computer players.
